# v6.17 OBS·PRISM 개별 화면 통합 패치

## 적용
기존 서버 프로젝트에 ZIP의 파일을 동일한 경로로 덮어쓰고 전체 재배포하세요. public/fonts 폴더도 포함해야 합니다. 서버 파일·화면 파일이 함께 바뀌었습니다. 추가 SQL은 없습니다. v6.16.5까지의 변경을 포함합니다.
배포 후 콘솔 Ctrl+F5와 OBS/PRISM 브라우저 소스 새로고침을 해주세요.

## OBS와 PRISM 각각 설정
콘솔 → 오버레이 → OBS·PRISM 화면
1. ‘편집할 화면’에서 OBS용 또는 PRISM용을 고릅니다.
2. 박스 폭, 이름·금액 글자, 안쪽 상하 여백, 아이콘 크기, 간격, 공지 글자, 알림 폭·글자, 배경 투명도, 표시 항목을 조정합니다.
3. ‘선택한 화면 설정 저장’을 누릅니다.
4. ‘OBS용 주소 복사’는 OBS에, ‘PRISM용 주소 복사’는 PRISM에 각각 넣습니다.
소스 원본 크기는 우선 600×1200으로 설정하고 실제 방송 화면에서 각각 크기·위치를 맞추세요. 폰트는 CSS 원본 픽셀이며 방송 프로그램의 소스 배율에 따라 최종 크기가 달라집니다.

## 주소
/overlay3-obs.html?station=방송국&token=기존토큰
/overlay3-prism.html?station=방송국&token=기존토큰
두 페이지는 같은 후원 데이터를 읽고 profile=obs/prism 설정을 따로 적용합니다. 기존 overlay3.html 주소는 OBS 프로필을 기본 사용합니다. 기존 토큰·방송국 정보는 유지됩니다. 미리보기 주소는 소리 중복을 막기 위해 mute=1이며, 복사하는 실제 방송용 주소에는 mute=1을 넣지 않습니다.

## 표시 변경
- 계좌후원명 최대 4글자 표시. 원본 입금 기록과 닉네임 매칭은 변경하지 않음. 계좌 리스트와 알림 이름 표시에서 적용
- 최소한의 안쪽 여백, 아이콘·이름·금액 간격 축소, 과도한 행 높이·알림 최소높이 제거
- 이름·금액 확대, 실제 렌더링 폭을 측정해 10,000,000 등 큰 금액도 자동으로 크기 조정
- 패널과 부모 너비를 일치시켜 화면 밖으로 밀리던 문제 수정
- 한글 웹폰트 자체 포함, 흡연·식사 프리셋 아이콘 SVG로 통일
- 공지는 기존 4줄·1.5초 정지 후 이동 유지
- 색상·하트 가림·닉네임 매칭·배경 투명도·알림 소리 등 기존 변경 유지

## 독립되는 항목
박스·글자·여백·아이콘·알림 크기와 배경 투명도, 표시 항목·방식은 OBS/PRISM별로 저장합니다. 후원·분배·프리셋·펀딩·닉네임 매칭 데이터는 공유합니다. 계좌 알림 재생 ON/OFF·표시 시간·투네 재생 대기 등 운영 알림 설정은 기존처럼 방송국 공통입니다.
설정을 저장한 프로필은 기존 공통 표시 설정보다 우선합니다. 화면별 표시 항목은 새 OBS·PRISM 화면 메뉴에서 관리하세요.

## 검증
기존 서버 테스트 28개 통과. 추가 프로필 저장·부분수정·동시저장·방송국 분리·관리자 권한·API 응답 테스트 통과. 실제 Chromium 브라우저에서 콘솔 저장/재조회, 두 전용 주소, 이름 4글자, 10,000,000 표시, 화면 경계 및 한 줄 알림을 확인했습니다. OBS/PRISM 앱 내부의 최종 화면과 오디오 출력은 현장에서 확인해야 합니다.
