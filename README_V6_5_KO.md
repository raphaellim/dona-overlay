# V6.5 · 콘솔 탭 전환 / 후원 대상 행 정리

변경 사항
- 콘솔 및 내부 페이지의 GET 조회는 웹소켓 직렬 요청 대기 없이 같은 서버의 HTTP로 처리합니다. 기존 인증 쿠키·권한 검사는 유지합니다.
- 저장·수정 요청과 실시간 알림은 기존 웹소켓 경로를 유지합니다. 자동 재시도로 저장을 중복 실행하지 않습니다.
- 후원 입력·승인 목록·최근 내역을 병렬로 불러옵니다. 동일한 설정 조회가 동시에 발생하면 한 요청을 공유합니다.
- 모드/대상·알림 설정만 3초간 재사용합니다. 실제 후원·승인 내역은 최신 조회합니다. 저장·실시간 변경·연결 상태 변경 시 캐시를 비웁니다.
- 방송 운영 탭의 불필요한 전체 설정 조회를 제거했습니다. 알림 설정/송출 토큰도 동시에 조회합니다.
- 탭을 누르면 로딩 상태를 먼저 표시하며, 이전 탭의 늦은 응답·오류가 새 화면을 덮지 않도록 방지합니다. 입력 중 이동 확인은 유지합니다.
- 첨부 화면의 후원 대상은 참여 / 이름 / 방송인 구분 / 별명 / 삭제를 PC 한 줄로 모았습니다. 좁은 모바일에서는 별명만 두 번째 줄입니다. 콘솔 참여자 입력도 같은 방식으로 정리했습니다.

검증
- 기존 서버 테스트 15개.
- 브라우저: 후원 입력, 권한, 미저장 입력 보호, 실제 알림 종료, 지연 조회와 빠른 탭 이동, 중복 조회 방지, PC/모바일 대상 행 배치.
- 테스트용 서버에서 웹소켓 인증에 1.8초 지연을 넣어도 콘솔 홈 조회는 따로 진행됨을 확인했습니다. 실서비스 속도는 서버·DB·네트워크 환경에 따라 달라집니다.

적용
전체 수정 소스입니다. 기존 .env / data / uploads를 유지하여 적용·재배포 후 콘솔에서 Ctrl+F5를 누르세요. OBS/PRISM 소스도 새로고침하세요. 추가 DB SQL 실행은 필요하지 않습니다.
