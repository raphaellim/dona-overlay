# v6.16 후원 알림·배경 투명도 패치

v6.15.1까지의 통합 변경 포함. ZIP의 파일을 서버의 같은 위치에 덮어쓴 후 전체 재배포하고, 콘솔 Ctrl+F5 및 OBS/PRISM 브라우저 소스를 새로고침하세요. 서버 파일도 바뀌었으므로 HTML만 교체하면 안 됩니다. 추가 SQL은 없습니다.

## 확인
콘솔 → 오버레이 → 알림·송출 주소
- 계좌 알림 자동 재생을 켜고 알림 설정 저장
- ‘투네 원본 재생이 끝날 때까지 계좌 알림 대기’는 재생 상태 어댑터를 쓸 때만 체크. 기본 OFF
- ‘후원 알림 테스트’를 눌러 열려 있는 오버레이에서 확인
- 테스트는 실제 후원 기록·정산·채팅 전송에 영향을 주지 않음
- 기존 투네 원본 모드 자체는 유지. 대기를 끄면 계좌 알림이 투네 원본과 겹쳐 나올 수 있음

## 투명도
오버레이 → 표시 방식 또는 알림·송출 주소 → 배경 투명도 · 알림 확인
오버레이 배경과 알림 배경을 각각 0~100%로 설정. 0%는 불투명, 100%는 완전 투명. 글자·아이콘의 불투명도는 유지. 저장 버튼 클릭 후 반영. 방송국별로 저장.

## 수정
재생 상태 어댑터 미연결 시 계좌 알림의 무기한 대기를 선택 설정으로 분리. 팝업을 패널 밖 body에 표시하고 위치·표시·높이를 명시해 부모 영역에 가려지지 않도록 수정. 오버레이3 및 별도 후원 알림 페이지 배경 설정 반영.

기존 서버 테스트 28개 및 대기/테스트큐/투명도 저장/방송국 분리/범위검사 통과. 실제 OBS·PRISM 화면 및 운영 서버 발송은 검증하지 않았습니다.

## v6.16.1 알림 잘림 수정
팝업을 패널 밖으로 이동한 뒤 패널 전용 확대 스타일이 적용되지 않던 부분 수정. 이름·금액 두 줄 배치, 이름32px·금액 최대36px, 최소높이230px 및 내용에 따른 자동확장. 메시지·분배의 두 줄 제한 제거. 별·금액별 색상·투명도 유지.
v6.16 적용 상태면 public 파일 4개를 같은 경로에 덮어쓰고 재배포 후 소스 새로고침. 브라우저 소스 자체 높이가 너무 작으면 바깥 영역은 표시되지 않으므로 OBS/PRISM 소스 높이를 최소600px 이상 확보하세요. 긴 메시지는 더 큰 높이가 필요합니다. 실제 PRISM 화면 검증은 수행하지 않았습니다.

## v6.16.2 투명도 적용 수정
뒤에 선언된 고정 배경색이 CSS 변수값을 덮어쓰던 문제 수정. 실제 오버레이·알림 요소에 저장한 배경색을 우선 적용하고 내부 중복 배경 제거. 설정 조회 캐시 사용 안 함, 파일 캐시 버전 갱신. DOM 검증에서 알파 0/100, 우선순위 및 실시간 설정 갱신 통과.
v6.16.1 적용 상태라면 public 파일 4개 교체 후 재배포, OBS/PRISM 소스 새로고침 및 콘솔에서 투명도 재저장. 기존 알림 확대 수정 포함.
