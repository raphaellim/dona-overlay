# v6.9 콘솔 후원 입력 정리

v6.8.1까지의 오버레이 색상·계좌 이름 가림·크리에이터 이름 4글자 가운데 정렬을 포함한 전체 소스입니다.

- 후원자·출처·총액을 묶고, 프리셋·펀딩 체크를 작은 선택 버튼으로 정리했습니다. 긴 설명을 줄이고 선택 결과를 바로 표시합니다.
- 기존 프리셋 단가에 따른 금액 채우기, 방송인별 횟수 계산, 펀딩 반영은 그대로 유지합니다.
- 같은 후원 입력 화면 아래에 현재 용돈, 증가/차감, 원 단위 금액, 용돈 반영 버튼을 추가했습니다. 후원 저장과 별도로 용돈만 조정하며 후원 매출은 추가하지 않습니다. 작성 중인 후원 입력도 유지합니다.
- 용돈은 현재 방송에만 반영됩니다. 입력 권한이 있는 관리자·매니저가 조정하며 변경은 작업 로그에 남깁니다.
- 콘솔 용돈 입력은 500 입력 시 정확히 500원입니다. 기존 리모컨의 천원 단위 해석은 유지됩니다.
- 데스크톱에서는 좌측에 후원 입력·용돈, 우측 위에 승인 대기·보류, 우측 아래에 최근 입력·수정을 배치했습니다.
- 우측 목록은 각각 5건 높이(행당 70px, 목록 350px)의 고정 영역이며 독립적으로 스크롤됩니다. 모바일에서는 세로로 배치합니다.

## 적용

기존 환경변수·운영 데이터·업로드 파일을 유지하고 소스를 교체한 뒤 서버를 재배포하세요. 콘솔은 Ctrl+F5로 새로고침하세요.
이번 v6.9 변경에는 추가 SQL이나 새 의존성이 없습니다. v6.7의 정산 기능 및 지정 문구 전송을 처음 설치하는 경우에는 README_V6_7_KO.md에 따라 sql/06-broadcast-finance.sql을 한 번 실행하세요.

서버 배포나 운영 DB 변경은 이 수정본 제작 과정에서 실행하지 않았습니다.

검증: 기존 후원·프리셋·펀딩 저장, 용돈 500원 정확 반영, 작성 중 후원 내용 유지, 용돈 입력 권한, 우측 두 목록의 5건 높이·독립 스크롤·수직 배치, 모바일 가로 넘침, 기존 서버 시작 및 정산·자동전송 회귀 테스트.
