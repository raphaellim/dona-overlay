# V6.3 · 알림 가운데 정렬 / 방송별 자동 수집

후원 알림의 이름·하트·금액을 가운데에 한 줄로 모았습니다. 금액은 숫자만 표시합니다.

자동 수집 규칙
- 방송 시작: 현재 방송에만 계좌/투네 알림을 저장합니다.
- 방송 선택 전환: 전환 시각 이후 들어오는 내역부터 새 방송으로 저장합니다. 새 방송이 준비/종료 상태라면 시작을 누를 때까지 저장하지 않습니다.
- 방송 종료: 계좌/투네 후보 저장을 중지합니다. 종료 중 들어온 내역을 다음 방송으로 이월하지 않습니다.
- 이전 방송 후보는 삭제하지 않고 해당 방송에 보존하며, 현재 방송의 승인 목록에서는 제외합니다.
- 방송 시작/선택/종료 시 투네 수집 연결을 갱신합니다. 재연결 지연 중에도 서버 저장 조건을 다시 확인합니다.
- 앱의 Android 알림 감지 자체는 계속될 수 있으나 방송 종료 중 서버에 보내진 내역은 저장하지 않습니다.

방송 생성·선택 페이지의 방송시작 / 방송종료 버튼이 기준입니다. 미션 타이머 시작/종료는 수집 상태를 바꾸지 않습니다.

적용: 전체 수정 소스. 기존 .env, data, uploads를 유지하고 재배포 후 OBS/PRISM 브라우저 소스를 새로고침하세요.
V6.1 콘솔 오류 수정과 V6.2 원 단위 제거도 포함되어 있습니다.
검증: 기존 9개 테스트 및 방송 상태·전환·지연 내역 제외 2개 회귀 테스트. 실제 은행 앱/투네 계정 연결은 검증하지 않았습니다.
