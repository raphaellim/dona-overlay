# v6.7 정산·지출·개인 공제 / 프리셋 간편 조정 / 지정 문구 자동전송

## 적용

이 ZIP은 v6.6까지의 수정을 포함한 전체 소스입니다. 기존 환경변수와 실제 운영 데이터는 그대로 유지하고 소스를 교체합니다.

1. Supabase SQL Editor에서 `sql/06-broadcast-finance.sql` 전체를 한 번 실행합니다. 기존 v5 설치 및 권한 테이블이 있는 환경의 추가 마이그레이션입니다. 새 설치는 기존 설치 SQL 적용 후 실행합니다.
2. 서버에 소스를 배포하고 재시작합니다. 새 npm 의존성은 없습니다.
3. 방송국 관리자 로그인 후 콘솔을 새로고침합니다.

배포나 운영 DB 변경은 이 파일 생성 과정에서 실행하지 않았습니다.

## 정산·지출

콘솔 **내역·정산**에 정산서 / 지출 원장 / 개인 공제 탭이 추가됐습니다.

- 정산서: 현재 방송·이전 방송·전체 방송 및 날짜 범위로 조회. 전체 또는 개인 선택 후 문서 열기 → 인쇄 / PDF로 저장. CSV 다운로드도 지원합니다.
- 개인별 정산서: 해당 방송인 수입, 공제 항목·공제금액, 최종 지급액(수입−공제). 지출 원장 항목은 표시하거나 개인에게 배분하지 않습니다.
- 전체 정산서: 전체 수입, 지출, 장부상 잔액, 미분배 계좌 금액 및 방송인별 수입·공제·최종 지급액.
- 지출 원장: 방송별로 카드 결제·정산금 지급·수수료 등을 기록. 항목, 거래처/수령인, 실제 원 금액, 지급수단, 승인/증빙 참조, 메모를 직접 입력합니다. 공통지출이나 자동 배분 개념은 없습니다.
- 영수증: 지출별 PDF/JPG/PNG/WEBP 1파일당 8MB까지 첨부. 추가 파일은 목록에서 계속 첨부할 수 있습니다. 공개 저장소가 아니며 관리자만 열 수 있습니다.
- 개인 공제: 방송인별 지급액 계산을 위한 별도 기록입니다. 실제 지급이나 카드 지출로 자동 합산하지 않습니다. 공제를 수정하려면 취소 후 새로 입력합니다.
- 지출 수정·취소와 공제 취소는 작업 로그를 남깁니다. 취소된 항목은 합계에서 제외하되 기록·영수증은 보존합니다. 동시 수정은 버전 검사로 충돌을 막습니다.
- 영수증 업로드 실패 시 지출 자체는 저장됩니다. 지출을 다시 등록하지 말고 목록의 영수증 첨부 버튼으로 재시도합니다.

수입은 저장된 원 금액을 사용합니다. 합방 계좌 입금과 방송인 분배 행을 전체 수입에 중복 가산하지 않습니다. 프리셋 횟수 조정과 펀딩 현재값 수정은 매출이 아닙니다. 플랫폼 표시 수입과 실제 입금액·수수료는 증빙과 대조해야 합니다. 문서는 세액 계산이나 신고를 대신하지 않는 관리 자료입니다.

## 프리셋

콘솔 **프리셋·펀딩 → 프리셋 횟수 조정**에서 방송인을 선택합니다. 각 프리셋 타이틀 바로 아래 **증가 / 차감** 버튼으로 횟수를 반영합니다. 세부 plus/minus 항목 선택은 제거했습니다. 프리셋 순횟수를 조정하며 수입이나 후원 알림을 추가하지 않습니다. 기존 세부 항목·단가는 후원 자동 계산용 설정으로 유지됩니다.

## 지정 문구 자동전송

콘솔 **연결·설정 → 외부 채팅 → 지정 문구 반복 자동전송**에서 설정합니다.

1. 기존 운영용 YouTube OAuth 계정을 연결하고 자동 전송할 라이브 주소·계정을 선택합니다.
2. 지정 문구 자동전송을 켜고 전송 간격(1~1440분)을 입력합니다.
3. 문구를 한 줄에 하나씩 입력합니다. 최대 20개, 문구별 180자입니다.
4. 자동전송 설정 저장을 누릅니다.

후원 자동전송과 별도로 켜거나 끌 수 있습니다. 콘솔에서 방송 상태가 방송 중일 때만 작동하며 방송 종료 시 중지합니다. 방송 시작 시각을 기준으로 간격이 지난 뒤 첫 전송하고 이후 한 문구씩 순서대로 보냅니다. 서버가 분 단위로 확인하므로 실제 시각은 약 1분 내외 늦어질 수 있습니다. 페이지를 닫아도 서버가 계속 실행 중이면 작동합니다.

서버 재시작·중복 실행에서도 같은 방송·같은 설정·같은 전송 차례는 DB의 고유 기록으로 중복 발송을 차단합니다. 누락된 과거 차례를 몰아서 보내지 않습니다. 전송 실패 시 같은 차례를 재시도하지 않고 다음 차례부터 계속합니다. 실패는 서버 로그에서 확인할 수 있습니다. 방송이나 전송 계정·주소 변경 시 설정을 확인하세요.

`npm test`, `npm run test:browser`, `npm run test:startup`.

검증 대상: 계좌 수입 중복 집계 방지, 정확한 원 단위, 개인 지출 제외, 공제·최종액, 한국 날짜 경계, CSV/HTML 이스케이프, 마이그레이션 재실행 및 비공개 설정, 관리자 권한과 방송국 격리, 등록 재시도 중복 방지·동시 수정 충돌, 영수증 첨부 UI, 프리셋 타이틀 조정, 문구 저장·재조회 및 주기·종료·방송 전환·서버 재시작 중복 차단.

실제 운영 DB와 실제 YouTube 계정으로의 외부 발송은 수행하지 않았습니다. 브라우저 및 API 테스트는 테스트 데이터/모의 전송으로 실행했습니다.
