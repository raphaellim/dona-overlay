# v6.15 입금자 닉네임 통합 패치

v6.13 이후 전체 소스에 같은 경로로 덮어쓴 후 서버를 재배포합니다. 콘솔 Ctrl+F5 및 OBS 소스 새로고침이 필요합니다. 이번에는 server.js·donor-identity.js·console.js도 함께 적용하세요. 오버레이 파일만 교체하면 등록 기능이 동작하지 않습니다. 추가 SQL은 없습니다. v6.14.5까지의 OAuth 분리·오버레이 디자인 수정 포함입니다.

## 등록
방송국 관리자 로그인 → 콘솔 → 연결·설정 → 입금자 닉네임
- 김민영 → 장마: 본명으로 입금해도 장마 표시
- 슈퍼맨 → 슈퍼맨: 등록된 닉네임 자체를 가림 없이 표시
- 미등록 이준호 → 이♥호: 두 번째 문자만 하트로 대체
- 미등록 두 글자 김영 → 김♥
- 닉네임 최대 12글자. 긴 닉네임은 이름 칸에 맞춰 글자 크기를 줄여 전체 표시
- 삭제 후 저장하면 다시 미등록 규칙 적용

각 방송국의 등록 목록은 분리됩니다. 입금자명이 정확히 같아야 연결됩니다. 동명이인은 입금자명만으로 구분할 수 없습니다. 실명 여부 자동 판별 기능은 아닙니다.
원본 후원 데이터·금액·정산 기록은 변경하지 않고 계좌 공개 이름만 변경합니다.
방송국 관리자만 원본 매칭 목록을 조회·수정할 수 있습니다.

## 적용 범위
계좌 리스트, 계좌 후원 알림, 계좌 후원 자동채팅, 계좌 누적 자동전송. 투네 단독 후원자명은 기존대로 유지합니다. 자유 입력 메시지·제목의 내용은 변경하지 않습니다.
이미 유튜브에 전송된 메시지는 바뀌지 않습니다. 새 전송부터 반영되며 오버레이 목록은 새로고침하면 반영됩니다. 이름 속 ♥도 금액대별 이름 색상을 따르며 한 글자 칸을 사용합니다.

검증: 기존 서버 테스트 28개, 신규 등록/방송국 분리/기록 보존/하트 표시 테스트 및 구문 검사 통과. 실제 브라우저 시각 검증 및 운영 Google 전송은 수행하지 않았습니다.
