# v6.12 갠방 용돈·프리셋 독립 표시

v6.11.1까지의 계좌·알림 금액별 색상, 메시지 및 기존 콘솔 수정을 포함한 전체 소스입니다.

## 설정

콘솔 → 오버레이 → 표시 방식에서 용돈 / 프리셋을 각각 체크하고 표시 저장을 누르세요.
방송 모드는 방송 운영 → 현재 방송에서 갠방/합방으로 설정합니다.

갠방:
- 용돈 OFF, 프리셋 ON: 🚬 +1  🍴 +2
- 용돈 ON, 프리셋 ON: 용돈: 30,000  🚬 +1  🍴 +2
- 용돈 ON, 프리셋 OFF: 용돈: 30,000
- 둘 다 OFF: 해당 줄을 숨깁니다.
- 크리에이터 현황을 꺼도 프리셋은 독립적으로 표시됩니다.

합방:
- 프리셋은 크리에이터 현황의 해당 방송인 옆에 표시합니다.
- 크리에이터 현황 OFF, 프리셋 ON이면 이름·프리셋만 표시하고 수입 금액은 숨깁니다.
- 용돈은 용돈 설정에 따라 별도로 표시합니다.

🚬는 흡연−금연, 🍴는 먹어−먹지마 최종 횟수입니다. 음수는 붉은색으로 표시합니다. 비활성화된 프리셋은 표시하지 않습니다. 사용자 정의 프리셋은 항목 이름 앞 두 글자로 표시합니다.
갠방은 방송의 활성 방송인 한 명을 사용하며 다른 방송인이나 국고의 횟수를 합산하지 않습니다. 갠방에서는 활성 방송인을 한 명으로 설정하세요.

## 적용

기존 환경변수·운영 데이터·업로드 파일을 유지하고 소스를 교체한 뒤 서버를 재배포하세요. 콘솔과 OBS/Prism 브라우저 소스를 새로고침하세요. 오버레이 단일 HTML만 교체하는 패치가 아니라 서버와 새 JS가 함께 들어 있는 전체 수정본입니다.
이번 변경에는 추가 SQL이나 새 npm 의존성이 없습니다. v6.7 정산·지정 문구 기능을 처음 설치하는 환경은 기존 README_V6_7_KO.md를 따릅니다.

검증: 갠방 네 가지 표시 조합, 크리에이터 현황 OFF에서도 프리셋 표시, 합방 전환과 프리셋 위치, 활성 방송인 선택, 음수·최종 횟수·비활성 프리셋 제외, 기존 후원·정산·채팅·메시지·별 반짝임·금액별 글자 효과 및 서버 시작.
운영 서버 배포는 이 수정본 제작 과정에서 실행하지 않았습니다.
