# V0718.7 미디어 슬라이드 성능 안정화

- 슬라이드 전체 동시 다운로드 제거: 현재 이미지 + 다음 이미지 1장만 유지
- 후원/공지/타이머 상태 갱신 시 슬라이드 DOM 재생성 방지
- `/uploads` 파일 30일 immutable 캐시 적용
- 미디어 업로드/삭제 자체로 `overlay:changed` 이벤트를 발생시키지 않음
- 업로드 응답에서 전체 미디어 폴더 재스캔 제거
- 미디어 목록 5초 서버 메모리 캐시 + 업로드/삭제 시 무효화
- `/api/overlay-state`에서 과거 방송 누적 `stationSettings` 제외
- 미디어 관리자 업로드 직후 서버 목록 중복 조회를 지연/최소화

이미지/영상 파일 자체는 수정하거나 변환하지 않습니다. 사용자가 적용한 WebP 파일은 그대로 유지됩니다.
