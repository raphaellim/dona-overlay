# 오버레이 네트워크 최적화 V0718

## 교체 파일

- `server.js`
- `public/overlay.html`
- `public/overlay_shorts.html`
- `public/overlay_luxury_api.html`
- `public/assets/js/roulette-overlay.js`

## 적용 내용

### 1. 미션 영상 자동 프리로드 제거

오버레이를 열 때 미션타이머 사용 여부와 관계없이 `/videos/mission_30sec.mp4`를 자동 다운로드하던 코드를 제거했습니다.

- 30초 경고 사운드 재생 유지
- 10초 숫자 카운트다운 유지
- 미션타이머 시작/정지/종료 표시 유지

### 2. 오버레이 전용 경량 API 추가

신규 API: `/api/overlay-state`

기존 `/api/summary`는 상세 페이지용 데이터까지 포함해 다음 데이터가 중복 전달됐습니다.

- 크리에이터 상세 행
- 도네이터 상세 행
- 계좌후원 상세 행
- 전체 후원 행

신규 API는 오버레이에 필요한 데이터만 반환합니다.

- 전체 설정
- 크리에이터별 합계 및 프리셋 합계
- 최근 계좌후원자 10명
- ALERT 복구용 최근 후원 160행

`summary.html`, `creator_detail.html`, `donor_detail.html` 등 기존 상세 페이지는 계속 `/api/summary`를 사용하므로 영향을 받지 않습니다.

### 3. 최초 소켓 연결 중복 조회 제거

기존에는 오버레이 최초 `refresh()` 직후 Socket.IO 연결 완료 콜백에서도 다시 `refresh()`가 실행될 수 있었습니다.

- 최초 연결: 기존 최초 조회만 사용
- 재연결: 놓친 변경 복구를 위해 1회 조회

### 4. 이벤트별 API 분리

- 일반 설정·후원 변경: 경량 오버레이 상태만 조회
- 룰렛 변경: `/api/roulette`만 조회
- 수동 사운드 변경: `/api/sound-events`만 조회

룰렛 또는 수동 사운드 이벤트마다 전체 후원·공지 데이터를 다시 받던 동작을 제거했습니다.

### 5. 수동 사운드 중복 조회 제거

일반 상태가 변경될 때마다 `/api/sound-events`를 추가 호출하던 동작을 제거했습니다.

수동 사운드는 다음 경우에만 확인합니다.

- Socket.IO 연결 직후
- 수동 사운드 이벤트 수신 시
- Socket.IO 장애 상태의 안전 동기화 시

### 6. 보조 오버레이 1초 폴링 제거

`overlay_shorts.html`과 `overlay_luxury_api.html`에서 1초마다 전체 데이터를 조회하던 코드를 제거하고 메인 오버레이와 동일한 Socket.IO 이벤트 방식으로 변경했습니다.

### 7. Socket.IO 장애 시 폴링 완화

정상 연결 중에는 폴링하지 않습니다.

연결 장애가 지속되면 상태 복구 간격을 자동으로 늘립니다.

- 장애 시작 후 1분: 15초
- 1분~5분: 30초
- 5분 이후: 60초

룰렛 장애 복구 폴링은 5초에서 15초로 변경했습니다.

## 안전장치

`overlay.html`은 신규 `/api/overlay-state`가 아직 배포되지 않았거나 일시적으로 실패할 경우 자동으로 기존 `/api/summary`를 사용합니다.

배포 순서가 순간적으로 어긋나도 오버레이가 빈 화면이 되지 않도록 구성했습니다.

## 변경하지 않은 기능

- 계좌후원 롤링
- 크리에이터 합계
- 프리셋 수량
- 공지
- 용돈
- 펀딩
- 노래방
- 미션타이머 사운드 및 10초 카운트다운
- 룰렛 실행 및 결과 표시
- 상단 슬라이드 표시
