# 오버레이 최신 버전 자동 갱신 패치

WebSocket v4.1 통합 패키지를 적용한 기존 서버에 사용하는 추가 패치입니다.
server.js, collection-ws.js, public/collection-socket.js를 같은 경로에 덮어쓰고 Railway를 재배포하세요. SQL·앱·Java 변경은 없습니다.

최초 적용 후 OBS/프리즘 브라우저 소스를 한 번 새로고침하세요. 기존 코드가 켜져 있으면 새 자동 갱신 기능도 아직 로드되지 않았습니다.
이후 HTML/JS/CSS는 캐시를 저장하지 않습니다. 오버레이/합산표/알림 전용 화면은 기존 웹소켓 재연결 시 서버 시작 버전을 비교해 변경되었으면 자동 새로고침합니다. 추가 주기 조회는 없습니다. station/token 등 주소 설정은 유지하고 v는 자동 변경합니다.
관리·후원입력 화면은 작성 중인 값을 보호하기 위해 자동 새로고침하지 않습니다. 이미지·영상·음원 캐시는 유지합니다.
서버 재시작 때도 버전이 바뀌어 새로고침됩니다. 서버 파일 변경은 재배포/재시작이 필요합니다. 단일 서버 인스턴스 기준이며 여러 replica에 연결하는 구성은 버전 공유 설계가 추가로 필요합니다.
배포 순간 새로고침으로 진행 중인 알림·애니메이션이 끊길 수 있으므로 방송 중 재배포는 이 동작을 고려하세요.
실제 Railway·OBS·프리즘 검증은 수행하지 않았습니다.
