# v6.13 용돈·프리셋 저장 및 방송 모드 동기화 수정

이전 수정본의 기존 컨트롤 노출 설정과 콘솔 표시 설정이 분리되어 있던 부분을 수정했습니다. v6.12까지의 전체 기능과 금액별 글자 효과를 포함합니다.

## 수정

- 콘솔 오버레이 → 표시 방식에 용돈 / 프리셋 개별 체크를 표시합니다. 화면 제목에 v6.13을 표시합니다.
- 콘솔 표시 저장 후 서버 값을 다시 조회해 선택한 항목이 실제 저장됐는지 확인합니다.
- 콘솔에서 저장한 노출 상태가 기존 컨트롤의 설정에도 저장됩니다. 기존 컨트롤에서 용돈·프리셋을 변경해도 콘솔 표시 설정에 동기화됩니다.
- 기존 컨트롤 기본/노출 영역에도 프리셋 체크를 추가했습니다.
- 갠방·합방 드롭다운 변경 시 즉시 저장하고 '갠방 적용 완료' / '합방 적용 완료'를 표시합니다. 이름·대상 수정은 참여자 저장 버튼을 사용합니다.
- 갠방 전환 시 활성 방송인이 여러 명이면 첫 번째 활성 방송인 한 명만 유지합니다. 다른 방송인을 사용할 때는 참여자 체크를 변경하고 저장하세요.
- 오버레이 모드 조회는 실제 수집 모드와 같은 설정 함수를 사용합니다. 새 방송의 합방 기본 모드도 동일하게 적용됩니다.
- 갠방: 프리셋만 / 용돈만 / 한 줄 함께 표시를 지원합니다. 합방: 프리셋을 방송인별로 표시합니다.
- 오버레이 표시 설정의 늦은 이전 응답이 새 모드 상태를 덮어쓰지 않도록 했습니다.

## 적용

public 파일만 덮어쓰지 말고 이 ZIP의 서버 파일까지 전체 소스를 함께 교체하고 재배포하세요. 기존 환경변수·데이터·업로드 파일은 유지합니다. 콘솔은 Ctrl+F5, OBS/Prism 브라우저 소스도 새로고침하세요.
콘솔 오버레이 표시 화면의 제목이 '오버레이 표시 · v6.13'인지 확인한 후 용돈/프리셋을 선택하고 표시 저장을 누르세요. 이번 변경에는 추가 SQL이나 새 npm 의존성이 없습니다.

프리셋 항목 자체가 사용 중이어야 횟수가 표시됩니다. 프리셋·펀딩 설정에서 사용할 항목을 활성화하고, 오버레이 표시의 프리셋 체크로 화면 표시를 조절합니다.

## 검증

28개 테스트, 브라우저 테스트 8개 및 서버 시작 통과.
새 통합 테스트는 실제 alert-coordinator/collection-review/overlay-preferences 라우트를 실행해 표시 저장 후 재조회·새로고침, 설정 양방향 동기화, 갠방·합방 즉시 저장 및 별도 오버레이 탭의 실시간 전환을 확인합니다. DB와 실제 방송은 테스트 저장소/테스트 데이터로 대신하며 운영 서버 배포는 실행하지 않았습니다.
