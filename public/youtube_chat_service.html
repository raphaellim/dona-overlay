방송 선택

라이브 방송 주소를 입력하세요. 다른 채널 방송 주소도 사용할 수 있습니다.

채팅 계정

연결된 계정이 없습니다.

섞기는 전송할 때마다 랜덤 문구와 저장된 수동 문구를 골라 보냅니다. 수동 문구가 비어 있으면 랜덤만 사용합니다. 전체 적용 시 입력을 비우면 기존 계정별 수동 문구를 유지합니다.

전송 꾸미기

계정 전송 순서는 항상 랜덤하게 섞습니다.

랜덤 형식: 떠ㅡㅡㅡ기ㅡㅡㅡ업 / 떠기업 🌸💗 / 🩵🌷🌼. 이모지만 나올 때는 공용 멘트와 개별 멘트를 넣지 않습니다. 계정 전송 순서도 매번 섞습니다.

이모지 코드는 실제 라이브 채팅에서 표시 여부를 확인하세요.

메시지 작성

랜덤 형식 사용 시 계정별 개별 멘트는 적용되지 않습니다. 공용 멘트를 비우면 이모지만 보냅니다.
서버 연동 전에는 미리보기만 가능합니다. 계정 인증 및 실제 전송에는 서버 API가 필요합니다.
