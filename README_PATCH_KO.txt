- 크리에이터 이름은 최대 4글자 표시합니다.
- 2·3글자 이름도 4글자 폭 안에 균등 배치합니다.
- 계좌 골드 #FFD166 / 현재용돈 민트 #4DE2B1 / 크리에이터 누적현황 핑크 #FF79BD.
- 용돈이 음수일 때는 기존의 붉은색을 유지합니다.

저장된 원본 이름, 정산서, 채팅 전송 내용은 변경하지 않습니다.
이 패치는 오버레이3 계좌 명단과 크리에이터 현황의 표시를 수정합니다.
오버레이 제목은 기존 설정의 방송 타이틀 값을 사용합니다.

4글자 제한, 동일 폭과 균등 배치, 안전한 문자 출력, 세 항목 색상을 확인했습니다.
