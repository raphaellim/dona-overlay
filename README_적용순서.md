# v6.16.7 간편 목록·재생 관리 수정 패치

v6.16.6 통합 패치가 적용된 서버용 추가 패치입니다.

## 적용
1. 현재 파일과 DB를 백업합니다.
2. Supabase SQL Editor에서 `sql/002_alert_manual_queue.sql`을 먼저 실행합니다. v6.16.6의 001 SQL이 먼저 적용되어 있어야 합니다.
3. 루트의 `alert-studio.js`와 `public` 폴더를 서버의 같은 위치에 덮어씁니다. 기존 public 폴더 전체를 삭제하지 마세요.
4. 서버를 재시작하고 콘솔과 OBS/프리즘 알림 소스를 새로고침합니다. 추가 npm 설치는 없습니다.

## 등록
후원 이미지·사운드 화면에서 사용 / 이름 / 금액 / 이미지 / 음원만 등록합니다.
이미지·음원을 여러 개 선택해 먼저 올린 다음 엑셀 셀을 붙여넣거나 XLSX, CSV, TSV, TXT를 가져옵니다.
열 순서는 `이름 | 금액 | 이미지 파일명 | 음원 파일명`입니다. 마지막 두 칸은 비워도 됩니다.
파일명은 확장자까지 일치해야 합니다. 가져오기 검사 → 목록 추가 → 설정 저장 순서입니다.
금액은 원 단위이며 정확히 일치하는 첫 번째 사용 중 항목이 선택됩니다. 기존 범위 규칙은 유지하며 금액을 수정하면 정확한 금액 규칙으로 바뀝니다.
v6.16.6에서 올렸던 파일은 원래 파일명을 저장하지 않았으므로 직접 선택하거나 다시 업로드해야 파일명 자동 연결을 쓸 수 있습니다.

## 재생·다시 재생
알림 방식을 독립 이미지·사운드로 저장하고 화면에 표시된 주소를 별도 OBS/프리즘 브라우저 소스로 추가하세요. OBS 시작 크기는 600×400입니다.
목록의 재생 버튼은 콘솔에서 소리를 내는 버튼이 아니라 등록한 방송 소스에 재생을 요청합니다. 소스가 열려 있어야 합니다.
자동 재생을 끄면 대기 항목에서 원하는 알림의 재생을 누릅니다. 재생 중인 알림이 있으면 끝난 뒤 선택한 항목부터 재생합니다. 이미 재생 중인 항목은 취소할 수 없습니다.
재생 완료 또는 실패·취소 목록에서 다시 재생할 수 있습니다. 화면과 소리만 새 알림으로 재생하며 후원금, 누적, 분배, 프리셋, 채팅을 다시 반영하지 않습니다.
독립 모드에서는 기존 현황 오버레이의 후원 알림을 끕니다.

## 정해진 크기와 제한
이미지는 비율을 유지해 최대 480×270으로 표시합니다. 업로드 시 최대 960×540 WebP로 축소합니다. 원본 이미지 15MB 이하, 변환 결과 2MB 이하입니다.
음원은 MP3/WAV/OGG, 10MB 이하, 180초 이하이며 기본 볼륨 80%입니다. 미디어 준비 후 1초 대기 → 음원 재생 → 실제 종료 후 1초 대기 후 알림이 닫힙니다.
목록은 최대 300개, 파일은 방송국별 200개, 화면은 50개씩 표시합니다. 목록 가져오기 파일은 2MB 이하입니다. XLSX의 첫 시트를 읽습니다.
엑셀 파서는 가져올 때만 별도 Worker에서 실행하고 종료합니다. 미디어는 순서대로 업로드하며 객체 URL·비트맵·리스너를 정리합니다. 큐 화면은 변경 이벤트와 수동 새로고침으로 갱신하며 상시 짧은 주기의 조회를 추가하지 않습니다.
기존 v6.16.6의 GPU 절감과 독립 재생 단일 플레이어 잠금, 미디어 해제 로직을 유지합니다. 실제 OBS/프리즘 환경의 GPU 수치는 별도 확인이 필요합니다.

기존 ALERT_MEDIA_DIR 영구 디스크 설정은 유지하세요. SheetJS 0.20.3을 동봉하여 XLSX 가져오기 시 외부 CDN을 호출하지 않습니다. 라이선스는 public/assets/js/SheetJS-LICENSE.txt에 있습니다.
