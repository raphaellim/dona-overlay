v6.16.5 통합 시안 반영 패치 · 300px

적용: 서버 public 폴더를 백업한 뒤, 압축파일 public 안의 파일 5개를 같은 위치에 덮어쓰세요.
서버를 재시작하고 OBS/PRISM 브라우저 소스를 한 번 새로고침하세요.
이번 화면 변경 대상은 overlay3.html입니다. overlay.html/overlay2.html은 수정하지 않습니다.

- 본문 폭 300px. 그룹 사이 5px 간격.
- 그룹별 왼쪽 세로바 + 하단 가로 구분선 연결. 가로선 왼쪽 40% 그룹 색상.
- 펀딩 그래프: 짙은 청록 바탕, 고정 민트 그라데이션. 달성률/남은 목표 대비 강화.
- 공지: 설정한 색상 계열을 밝고 부드럽게 조정(HEX 색상). 4줄 노출과 1.5초 머무름 유지.
- 합방 누적현황: 만원 단위, 소수 첫째 자리까지. 1,000,000 → 100 / 123,000 → 12.3.
  제목에 단위: 만 표시. 실제 저장 금액, 계좌·후원 알림 금액은 그대로 유지.
- 갠방: 용돈과 프리셋을 같은 줄에 표시. 각 프리셋만 플러스 청록/마이너스 적갈색/0 회색 배경.
  기존 아이콘 유지. 별도 카드/긍정·주의 문구는 추가하지 않음.
- 계좌명 4글자, 알림 전체 이름, 계좌 아이콘 비율 80% 유지.
- 기존 중복 조회/화면 밖 애니메이션 부하 완화 포함.

확인: 브라우저에서 300px, 계좌 4글자+10,000,000, 합방 프리셋 2개 및 100/12.3 한 줄,
갠방 프리셋 +3/-2와 용돈 30,000 한 줄, 런타임/스크립트 오류 없음 확인.
원복: 백업한 파일을 복구하고 브라우저 소스를 새로고침하세요.
