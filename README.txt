YouTube 후원 자동채팅 전체 패치 v2 (0928)

교체 파일:
- server.js
- youtube-chat.js
- public/youtube_chat_service.html

추가 기능:
1. 후원 등록 자동채팅 1차/2차 전송
2. 현재 누적후원현황 수동 전송 버튼
3. 프리셋 후원 자동 표기: {프리셋} 치환값
4. 자동채팅 문구 직접 수정 가능

예시:
라파엘 10 계좌 → 빵떠기(10) 흡연 흡연+8
현재 누적후원현황 빵떠기(20)

주의: 기존 Render의 YouTube OAuth 환경변수/연결 계정 설정은 그대로 사용합니다.
