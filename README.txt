V7 변경
1. 주기 자동 현황전송을 모바일 브라우저 타이머가 아닌 서버 타이머로 변경
   - 리모컨을 닫아도 동작
   - 설정 저장 후 선택한 5/10/20/30/60분 간격으로 전송
2. 후원 저장 시 자동채팅은 서버에서 계속 실행
3. 누적후원 문구 축약 + 크리에이터별 하트 구분
   예) 💰 누적 ❤️ 떠기 247.6 🧡 또영 126.6 💜 나나 31.6
4. 프리셋은 최종값만 표시
   흡금 = 흡연(+) - 금연(-)
   먹먹마 = 먹어(+) - 먹지마(-)
5. 프리셋+용돈 동시 선택 시 한 메시지로 전송
   예) 🎯 🚬 흡금 +3 🍴 먹먹마 -2 💵 용돈 +35
6. 선택한 정상 YouTube 계정만 방송 확인/전송에 사용(V6 수정 유지)

주의
- 배포 후 donation_chat_remote.html에서 연결정보/자동전송 설정을 한 번 저장하세요.
