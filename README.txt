v6.16.5 오버레이 부하 완화 패치

서버를 중지하고 기존 public 폴더를 백업한 뒤, 이 압축파일의 public 안 파일 4개를 같은 위치에 덮어씁니다.
서버를 다시 실행한 후 OBS/PRISM 브라우저 소스를 한 번 새로고침합니다.

수정 내용
- 동시에 발생한 같은 API 조회를 공유합니다. 완료된 응답을 계속 캐시하지 않습니다.
- 설정이 동일하면 대상/표시 변경 이벤트를 재발행하지 않습니다.
- 화면 밖 계좌 후원 줄의 그라데이션 애니메이션을 멈춥니다. 현재 표시되는 줄의 효과는 유지합니다.
- 같은 타이머/연결 상태 문구를 반복해서 DOM에 쓰지 않습니다.
- 기존 v6.16.5 배치, 계좌명 4글자, 알림 전체 이름, 세로 중앙 별표를 유지합니다.
- 앞 아이콘은 이름 크기의 80%로 맞춥니다.

주의: 이 패치는 부하 요인을 줄이는 수정이며 사용자 PC의 Chrome 전체 메모리나 GPU 사용량 감소를 보장하는 측정 결과는 아닙니다.
원복은 백업한 public 파일을 복구한 후 브라우저 소스를 새로고침하면 됩니다.
