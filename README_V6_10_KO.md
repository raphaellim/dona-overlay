# v6.10 메시지 전달 및 알림 가독성 수정

v6.9까지의 전체 수정이 포함된 소스입니다.

## 변경

- 후원 입력에서 횟수 입력과 단가로 금액 채우기 버튼을 제거했습니다. 총액·방송인별 분배금액을 입력하고 프리셋/펀딩만 선택하면 기존 계산식으로 자동 반영합니다. 선택 시 입력 금액을 덮어쓰지 않습니다.
- 수동 후원 입력 메시지가 메모에만 저장되고 알림 메시지로 전달되지 않던 부분을 수정했습니다. 메시지를 알림용 메타데이터에 함께 저장해 실시간 전송과 재연결 시에도 읽도록 했습니다.
- 오버레이3 알림의 고정 180px 높이를 해제했습니다. 메시지는 최대 3줄, 분배는 최대 2줄로 표시하며 내용에 맞게 알림 높이가 늘어납니다.
- 계좌 후원 / 투네 후원은 27px 굵은 글씨로 별도 줄에 크게 표시합니다. 출처·후원자·금액·메시지를 가운데 정렬했습니다.
- 출처·후원자·금액 글자에만 무지개 그라데이션이 자동으로 흐릅니다. OBS에서 마우스를 올릴 필요가 없습니다. 상자나 별에 무지개 이동 효과를 주지 않습니다.
- 기존 별 반짝임과 계좌 등급별 별·다이아 효과는 유지했습니다. 움직임 최소화 설정에서는 글자 애니메이션을 끕니다.
- 독립 알림 페이지 donation-alert.html에도 메시지·출처 글자 효과를 적용했습니다.
- 기존 이름 가림·4글자 가운데 정렬·항목별 컬러, 용돈 입력, 우측 목록 5건 독립 스크롤을 모두 포함합니다.

## 적용

기존 환경변수·운영 데이터·업로드 파일을 유지하고 소스를 교체한 뒤 서버를 재배포하세요. public/donation-alert-text.css는 새 파일이므로 함께 올려야 합니다. 콘솔과 OBS/Prism 브라우저 소스를 새로고침하세요.

이번 변경에는 추가 SQL이나 새 의존성이 없습니다. v6.7 정산·지정 문구 기능을 처음 설치하는 환경은 기존 README_V6_7_KO.md의 설치 절차를 따릅니다.

검증: 프로덕션 수동 후원 저장 함수의 메시지 메타데이터 및 프리셋/펀딩 계산, 콘솔 메시지 요청과 횟수 입력 제거, 실제 오버레이3/독립 알림의 메시지 표시·출처 크기·가운데 정렬·무지개 글자·기존 별 반짝임·문자 안전 출력·움직임 최소화, 기존 권한·중복 집계·정산 및 서버 시작.

운영 서버 배포 및 실제 YouTube 발송은 이 수정본 제작 과정에서 실행하지 않았습니다.
