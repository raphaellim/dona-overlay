# v6.14 방송국별 유튜브 API 통합 패치

v6.13 전체 수정본 위에 적용하는 패치입니다.

## 적용
1. 기존 서버 소스를 백업합니다.
2. 이 ZIP의 server.js, youtube-chat.js, public 폴더를 서버 프로젝트의 같은 위치에 덮어씁니다. public 폴더 자체를 삭제하지 마세요.
3. 서버를 재배포하고 콘솔을 Ctrl+F5로 새로고침합니다.
4. 콘솔 → 연결·설정 → 외부 채팅 → ‘이 방송국의 Google Cloud API 연결’에서 방송국별 OAuth 클라이언트 ID·보안 비밀번호를 저장합니다.
5. 화면에 표시된 콜백 주소를 각 Google Cloud 프로젝트의 승인된 리디렉션 URI에 등록한 후 구글 계정을 다시 연결합니다.

## 서버 환경변수
YOUTUBE_SERVICE_REDIRECT_URI는 기존 HTTPS 콜백 주소를 유지합니다.
YOUTUBE_SERVICE_CHAT_ENCRYPTION_KEY는 기존 값을 반드시 유지합니다.
운영채팅은 공통 Client ID/Secret으로 대신 연결하지 않습니다. 일반 테스트용 youtube-chat은 기존 구성을 유지합니다.
각 방송국의 별도 Google Cloud 프로젝트에서 YouTube Data API v3를 활성화하고 웹 애플리케이션 OAuth 자격증명을 사용하세요. 별도 API 키 입력은 필요 없습니다.
같은 프로젝트 자격증명을 여러 방송국에 입력하면 Google 프로젝트 할당량은 공유됩니다.

## 포함 변경
- v6.13 서버를 기준으로 병합해 갠방/합방 및 용돈·프리셋 표시 저장 수정 유지
- 방송국별 OAuth 자격증명 암호화 저장·인증·토큰 갱신 분리
- 후원 자동전송·누적 주기전송·지정 문구 자동전송의 방송국별 설정 확인 연결
- 다른 방송국 설정·연결 유지, 자격증명 변경 시 기존 토큰 재연결 요구
- 공통 프로젝트 토큰을 사용하던 방송국도 방송국별 설정 저장 후 구글 재연결 필요

추가 SQL은 없습니다. v6.13까지 필요한 기존 SQL은 적용되어 있어야 합니다.
별도 데이터 파일·환경변수 파일·오버레이 파일을 교체하지 않습니다.

## 검증
기존 서버 테스트 28개 및 방송국 OAuth 분리 모의 테스트 통과. server.js·youtube-chat.js·UI 스크립트 구문 검사 통과.
현재 실행 환경에 Chromium 실행 파일이 없어 브라우저 검증은 완료하지 못했습니다.
실제 Google 로그인 및 유튜브 발송은 배포 후 확인이 필요합니다.

## 오버레이 가독성 추가 수정
- 펀딩현황 제목 고정, 펀딩명·현재/목표 금액을 그래프 내부에 배치
- 달성률·남은 금액은 그래프 아래 표시
- 공지 3줄 고정: 1.5초 정지 후 0.25초 동안 한 줄 이동, 반복 갱신 시 위치 유지
- 공지는 입력한 줄바꿈을 기준으로 이동하며, 한 줄 너비를 넘는 문구는 말줄임 표시
- 갠방 용돈·프리셋 글자 약 30% 확대 및 행 높이·여백 확대
- 기존 방송국별 API 분리 통합 패치 포함
- 추가 DOM/가상 타이머 검증 통과. 브라우저 화면 검증은 Chromium 미설치로 수행하지 못함.
