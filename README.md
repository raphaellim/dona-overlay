# LiveCatch — 2026-10-29 최신 전체 소스

이 폴더가 서버 전체 소스입니다. 이전 패치 ZIP 위에 적용하는 형태가 아니며, 별도의 업데이트·패치 적용·시작 스크립트가 필요하지 않습니다.

## 실행

Node.js 22 이상에서 실행합니다.

```sh
npm ci --omit=dev
npm start
```

시작 파일은 `server.js`입니다. Railway는 포함된 Dockerfile로 빌드하거나 위 명령으로 실행할 수 있습니다.

## 기존 서버 교체

기존 GitHub 저장소를 백업한 뒤 **소스 파일만** 이 ZIP 내용으로 한 커밋에서 교체합니다. ZIP 안의 `package.json`, `server.js`, `public` 등이 저장소 최상단에 와야 합니다. 저장소나 Railway 서비스를 삭제하지 않습니다.

기존 Railway Variables, 도메인, 볼륨 마운트, 데이터베이스는 그대로 유지합니다. 기존 DATABASE_URL, 미디어 저장 경로, 암호화 키를 바꾸지 않습니다. 볼륨이나 DB를 초기화하거나 업로드 파일을 지우지 마세요. 기존 계좌 수집 앱 API와 Java 수집 연결은 유지됩니다. Java는 함께 제공됐던 v6.16.8.73 소스를 사용하며 이 Node 정리에서 변경하지 않았습니다.

음원·이미지·알람 그룹의 식별자 및 저장 데이터를 변환하거나 재생성하지 않습니다. 미디어 파일이 기존 영구 저장소에 있어야 하며, 이미 404인 유실 파일을 복원하는 패키지는 아닙니다.

`sql`은 필요한 DB 정의 및 테스트용 SQL입니다. 기존 서버 교체 때 일괄 재실행하지 않습니다. 재생 제어에 필요한 추가 테이블은 기존과 같이 자동 확인합니다. 새 빈 데이터베이스의 모든 기능을 초기 설치하는 절차는 이번 교체 검증 범위가 아닙니다.

## 화면과 실시간 반영

관리 화면은 `/`에서 실행되고 관리 메뉴를 바꿔도 주소는 `/`로 유지합니다. 이전 `console.html` 주소는 이 화면으로 연결됩니다. 실제 API·소스 주소는 브라우저 개발자 도구에서 확인할 수 있습니다. 주소를 간단하게 하는 기능은 접근 권한을 대신하지 않습니다.

방송 운영·후원 승인·정산·디자인·알람 설정은 관리 메뉴에서 사용합니다. 고유 기능이 있는 세부 설정 화면과 OBS/프리즘 송출 페이지는 유지했습니다. 이전 오버레이 별칭은 `overlay3.html`로 연결하며 현재 `overlay3.html`, `sound-alert.html`, Java `native-toonie` 송출 주소는 계속 사용할 수 있습니다.

상위 관리 화면과 포함된 설정 화면은 하나의 실시간 연결을 공유합니다. 오버레이 최초 상태는 한 번 읽고 공지·표시·프리셋 등은 변경 항목을 전달합니다. 재연결이나 이벤트 누락 시 전체 상태를 한 번 다시 읽습니다. 되돌릴 수 있는 디자인·표시 설정은 먼저 표시하고 저장 실패 시 복구합니다. 후원·분배·스택 등 금전 관련 처리는 저장을 먼저 확인합니다.

## 확인

```sh

npm run test:startup
npm run test:ui
```

자동 검증: 금액·정산·승인·방송국 격리, 재생 시 스택 반영, 실시간 패치 및 저장 실패 복구, 관리 시작 경로·이전 주소 연결, 실제 오버레이 DOM 변경과 추가 조회 방지, 포함 화면 연결 재사용.

실제 방송 환경의 OBS/프리즘 장시간 GPU·메모리 사용량과 외부 투네 재생은 별도 실사용 확인이 필요합니다. 투네 원본의 미재생 알림 자동 재전송은 이번 정리에서 새로 구현한 기능이 아닙니다.

## 2026-10-29 재검증 보완 (6.16.8-rebuild.75)

실제 WebSocket 전송에서 변경 데이터가 누락되던 문제를 수정했습니다. 공지·표시 변경(overlayPatch), 타이머, 알람 일시정지·재개, 재생 설정, 노래방·스택 및 스타일 이벤트의 허용된 데이터가 방송국별 연결에 전달됩니다. 일반 state 이벤트에는 추가 데이터를 싣지 않습니다. 실제 WebSocket 인증·방송국 격리·변경 데이터 전달 검사를 test:ui에 포함했습니다.

포함된 설정 화면에서 Request 객체로 API를 호출할 때도 요청 방식·본문·헤더를 유지합니다. 현재 화면과 다른 문서에서 생성된 Request 객체도 처리합니다. 참조되지 않던 이전 overlay3-alert.js 및 overlay3-profiles.js를 제거했습니다. 송출 HTML과 계좌수집 API, DB 스키마, 저장 경로, 미디어 및 그룹 식별자는 변경하지 않았습니다.

Java ZIP은 기존 프로젝트에 적용하는 파일 3개짜리 패치입니다. 전체 Java 소스·pom.xml·Dockerfile이 포함된 패키지가 아닙니다. 기존 Java 프로젝트를 삭제하거나 Node ZIP으로 교체하지 마세요.

OBS·프리즘 실사용 확인 시 동일 장면과 해상도에서 소스 OFF/ON을 비교하고, 10분·30분·60분 시점 GPU와 메모리를 기록하세요. 공지 변경·표시 ON/OFF·알람 일시정지/재개·연속 후원·연결 복구를 확인하세요. 이 검사는 아직 완료되지 않았으며, 장시간 실제 방송 성능 개선을 보장하는 결과는 아닙니다.

## 6.16.8-rebuild.77 룰렛 송출 연결 복구

기존 roulette 전용 DOM 이벤트에만 의존하던 송출 코드를 현재 collection:changed의 roulette/state 이벤트에 직접 연결했습니다. 재연결 시 상태 확인을 유지하고, 스크립트가 DOM 준비 후 로드되어도 초기화합니다. 종료 시 이벤트·회전·결과 타이머와 음원을 정리합니다. 룰렛 실행 후 실제 오버레이 DOM 표시 및 방송국/토큰 전달 검사를 추가했습니다. 별도 룰렛 송출 페이지나 DB 변경은 없습니다.
