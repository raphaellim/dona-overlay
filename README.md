# 오버레이3 디자인 패치
현재 V5 서버에 추가하는 패치입니다. 서버 전체 소스가 아닙니다.

## 적용
ZIP을 풀고 public 폴더의 파일 전체를 GitHub 프로젝트 public 폴더에 복사하세요.
overlay3.html / overlay3-alert.js는 추가 파일입니다. 루트 alert-coordinator.js도 서버 루트에 덮어쓰세요.
alert-queue.js는 기존 V5와 동일한 대기열 모듈입니다.
Commit → Push → Railway 배포 완료 후 새 주소를 열어주세요.
SQL 변경, 앱 재설치는 필요하지 않습니다.
collection-socket.js / overlay-display.js 및 V5 alert-config, overlay-state API가 기존 서버에 있어야 합니다.

## 주소
디자인 미리보기:
https://dona-overlay-production.up.railway.app/overlay3.html?demo=1&mute=1

실제 방송용:
https://dona-overlay-production.up.railway.app/overlay3.html?station=duugi&token=기존오버레이토큰

기존 overlay.html 주소에서 파일명만 overlay3.html로 바꾸면 됩니다.
OBS/PRISM 브라우저 소스에 사용하세요. 투명 배경이며 기존 위치 설정을 사용합니다.
오버레이3는 기본 폭 336px, 계좌 롤링 36px이며 ALERT는 내용에 따른 높이입니다.
ALERT 대기 중에는 공간을 차지하지 않습니다. 표시할 때 다른 영역 위에 겹쳐 뜨며 아래 패널은 움직이지 않습니다.
계좌를 꺼도 ALERT 표시와 글자 크기는 유지됩니다. 방송 종료 시 기존 정책대로 전체가 숨겨집니다.
mute=1은 오버레이3 ALERT 음소거용입니다. 다른 수동 사운드는 기존 설정을 따릅니다.
alerts=0은 오버레이3 자체 후원 ALERT를 끕니다.

## 운영
표시 패널과 통합/선택/슬라이드 모드는 기존 컨트롤 설정을 사용합니다.
공지, 펀딩, 노래방, 미디어는 기존 데이터와 렌더러를 유지하며 방송인 영역은 순위 디자인으로 변경합니다.
계좌 롤링 및 ALERT: 이름 → 아이콘 → 금액, 10만원 별, 30만원 다이아.
이름 효과는 글자 안에만 적용합니다.
ALERT에 메시지/분배 내역은 각각 한 줄로 표시하고 긴 문장은 생략합니다.
같은 후원을 표시하는 별도 donation-alert.html 소스가 있다면 동시에 사용하지 마세요.

내부 알림 모드에서는 자체 투네/계좌 ALERT가 같은 대기열을 사용합니다.
원본 투네 모드에서는 기존 원본 재생 상태 연동이 필요합니다.
원본 종료 자동감지를 새로 구현한 패치가 아닙니다.
재생 상태 미확인일 때 계좌 대기는 기존 정책대로 유지됩니다.
기존 자동 최신 버전 갱신은 collection-socket.js를 재사용합니다.

## 확인 범위
로컬 브라우저에서 예시 ALERT 표시, 계좌 아래 위치, 컴팩트 높이, 스크립트 실행을 확인했습니다.
실제 Railway 배포, 실제 투네 이벤트 및 OBS/PRISM 송출은 이 파일을 배포한 뒤 확인해야 합니다.

컴팩트 v2: 패널 간격 3px, 패널 패딩 3px/7px. 이름 26px, 금액 23px, 공지 23px, 방송인 26px.

## 통합박스 최종 디자인
외곽 박스 하나에 각 영역을 구분선과 색상 표식으로 표시합니다.
제목 Jua, 본문 Noto Sans KR 굵은 글꼴, 배경 진하기 65%.
웹폰트는 Google Fonts에서 로드되며 연결 불가 시 시스템 글꼴로 대체됩니다.
스타일 페이지 값은 오버레이3에 적용하지 않습니다.
방송인 타이틀은 컨트롤 '방송 타이틀', 공지는 '공지 타이틀', 노래방은 기존 노래방 타이틀을 사용합니다.
펀딩은 기존 등록 펀딩의 이름과 롤링을 유지합니다.
방송인은 후원금액 내림차순 순위 / 이름 / 원 단위 금액, 옵션은 아래 표시합니다.
'기타' 그룹 수령인은 순위에서 제외하며 항목(금액)으로 표시합니다.

추가된 루트 alert-coordinator.js도 서버 루트에 덮어써주세요.
기존 분류 테이블을 읽어 오버레이에 이름/그룹만 전달합니다. SQL 변경은 없습니다.
public/console.js는 기존 내비게이션 수정 포함 버전에서 스타일 메뉴만 제거했습니다.
creator_index.html의 오버레이 링크는 overlay3로 연결합니다.
station_style.html은 console.html로 이동하는 호환 페이지로 교체합니다.
이 ZIP의 모든 파일을 같은 경로로 덮어쓰세요.

표시 수정: 기존 크리에이터 ::before 너비/글자/여백 제거, 색상 표식 3px 고정. 기존 텍스트 그림자 및 펀딩/노래방 내부 배경 제거.

공지·펀딩·노래방·방송인 제목 옆 구분선 추가. 직전 패치 적용 시 public/overlay3.html만 교체하세요.

펀딩 디자인: 등록한 펀딩명을 제목으로 사용, 현재/목표 금액 원 단위 표시, 진행바·달성률·남은 금액. 여러 펀딩은 4초마다 순환. 제목 옆 구분선은 가상요소 대신 실제 요소로 렌더링.

프리셋: 크리에이터 이름 옆, 글자 16px. 기타 항목 16px. 용돈은 공지 아래 별도 행으로 기존 컨트롤 표시 ON/OFF와 금액을 사용하며 공지를 꺼도 표시 가능합니다.

ALERT 팝업: 계좌 아래 위치에 absolute로 표시합니다. 계좌 숨김 시 마지막 위치를 유지하며 다른 패널을 밀지 않습니다. 직전 버전에서 overlay3.html과 overlay3-alert.js 두 파일 교체.
