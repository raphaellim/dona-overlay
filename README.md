# ALERT 여백 축소 · 계좌 바로 아래 배치

직전 overlay-alert-independent-patch 적용 후 사용하는 추가 패치입니다.
public/overlay-alert.js 한 파일만 교체합니다. SQL/앱/오버레이 주소 변경 없음.

- 계좌 박스와 같은 화면상 폭, 계좌 하단에서 8px 아래 정렬.
- 바깥 여백 12px, 글자 크기 조정, 빈 메시지·분배 행은 공간을 차지하지 않음.
- 높이는 내용에 맞춰 압축. 일반 계좌 후원 예제 약 104px.
- 계좌 박스를 꺼도 마지막으로 측정한 위치와 폭 유지.
- 다른 박스의 표시 여부는 위치와 크기에 영향을 주지 않음.
- 계좌 박스가 표시 중일 때 위치/높이가 변경되면 ALERT 기준점도 따라감.
- 처음부터 계좌가 숨겨진 경우, 현황 패널 위치를 기준으로 기본 계좌 높이 140px을 가정한 대체 위치 사용. 실제 계좌를 한 번 표시하면 실제 하단 기준으로 맞춰짐.
- 창 크기 변경 시 화면에 맞춰 재배치.

적용: 기존 public/overlay-alert.js 백업 → 덮어쓰기 → Commit/Push → 배포 후 OBS/PRISM 소스 새로고침.
알림 재생 모드와 투네 대기 규칙은 변경하지 않습니다.

브라우저 검증: 계좌와 폭 동일, 계좌 아래 8px, 빈 메시지 공간 제거, 계좌 OFF 시 크기·위치 유지, 계좌 높이 변경 반영 통과.
운영 서버에 직접 배포하지 않았습니다.
