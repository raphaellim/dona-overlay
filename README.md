# 현황 오버레이 안의 독립 ALERT 고정 영역 패치

V5 기준 패치. overlay.html / overlay2.html / overlay2_fixed.html / overlay_luxury_api.html / overlay_shorts.html에 적용.

- ALERT를 document.body 바로 아래에 둡니다. 공지·계좌·순위·슬라이드 박스와 별개입니다.
- 고정 크기: 폭 700px, 높이 260px. 좁은 송출 화면에서는 폭만 화면 안으로 제한됩니다.
- 다른 박스의 표시/숨김·폭·합치기·슬라이드 전환은 ALERT 크기와 위치를 바꾸지 않습니다.
- 화면 중앙 고정, 긴 메시지는 정해진 영역 안에서 잘립니다. 전체 메시지는 후원 내역에서 확인합니다.
- 금색 테두리·별 반짝임·자동 종료.
- 기존 collection-socket.js 연결을 재사용합니다. iframe이나 추가 웹소켓 연결은 만들지 않습니다.
- 직접 이벤트와 상태 복구 응답이 같은 후원을 알려도 재생 중복을 제외합니다.

## 적용
1. 현재 public/overlay*.html을 백업.
2. ZIP의 public 폴더 내용을 기존 public 폴더에 덮어쓰기.
3. Commit / Push 후 Railway 배포 완료 확인.
4. OBS/PRISM의 기존 현황 오버레이 소스를 새로고침. 기존 주소를 그대로 사용합니다.
5. 별도 donation-alert.html 브라우저 소스를 이미 추가했다면 제거하세요. 현황 오버레이 안에서 ALERT를 한 번 재생합니다.
   별도 알림 소스를 유지하려면 현황 주소에 &alerts=0을 넣어 내장 ALERT를 끕니다.

SQL 변경·앱 재설치 필요 없음. 현재 주소의 station과 token을 유지하세요.

## 현재 native 대기 설정은 별개
이 패치는 표시 영역과 현황 오버레이 연결을 수정합니다. 투네 원본 종료 연동을 구현한 패치가 아닙니다.
투네 모드가 native이고 실제 재생 상태가 연결되지 않으면 계좌 ALERT는 계속 대기합니다.
즉시 자체 자동 알림을 사용하려면 운영 화면 → 오버레이 → 알림·송출 주소 → '자체 알림 · 공통 대기열' 선택 → 저장.
이때 기존 투네 원본 소스는 끕니다. 원본을 동시에 켜면 자체 투네 알림과 중복될 수 있습니다.

## 검증
실제 브라우저에서 모의 계좌 이벤트 재생, 700x260 크기, 모든 현황 박스 OFF 전후 동일 위치·크기, 박스 폭 변경 전후 동일 크기, body 직접 부착, 자동 종료, JS 오류 없음 확인.
운영 DB 및 실제 OBS/PRISM 기기 송출에서는 아직 검증하지 않았고 직접 배포하지 않았습니다.
웹페이지를 닫으면 브라우저의 재생 대기열은 사라집니다. 후원 원장은 유지됩니다.
