# V6.6 · 콘솔 프리셋·펀딩 관리 / 체크 입력

사용 순서
1. 콘솔 상단의 프리셋·펀딩 메뉴에서 항목을 설정합니다.
2. 프리셋 설정: 항목 이름, 추가/반대 이름, 단가, 사용 여부를 저장합니다. 단가는 실제 금액(예: 11900)을 입력합니다.
3. 펀딩 설정: 이름, 목표, 현재값, 사용 여부를 저장합니다. 목표·현재값은 만원 기준입니다. 예: 2000만원은 2000. 현재값 수정은 매출을 추가하지 않습니다.
4. 후원 입력에서 프리셋 한 항목과 펀딩 한 항목을 체크할 수 있습니다. 체크 후에도 실제 후원금은 한 번만 저장됩니다.
5. 금액이 비어 있으면 프리셋 체크 시 단가로 채웁니다. 횟수를 바꾸거나 단가로 금액 채우기를 누르면 단가×횟수로 채웁니다. 이미 직접 입력한 금액은 임의로 덮어쓰지 않습니다.
6. 참여 방송인이 한 명이면 분배 금액도 채웁니다. 여러 명이면 방송인별 분배금액을 입력하거나 균등 분배를 누르세요.
7. 프리셋 횟수는 각 방송인의 분배금액÷단가에서 정수 횟수로 계산됩니다. 남은 금액도 후원 매출에는 포함됩니다.
8. 펀딩은 이번 후원금 전체를 한 번 반영합니다. 콘솔 체크 입력은 23800을 펀딩 2.38만원으로 반영합니다.
9. 프리셋 횟수 조정 메뉴는 후원 매출 없이 특정 방송인의 횟수만 추가/차감합니다. 방송 시작 상태에서 입력 권한으로 사용할 수 있습니다.

자동 수집 승인
분배 확인 창에서도 프리셋·펀딩을 체크한 뒤 수정 저장 또는 승인할 수 있습니다. 분배 금액을 기준으로 프리셋 횟수와 펀딩을 반영합니다. 합방 계좌 입금 때 이미 보낸 알림·채팅은 분배 승인에서 다시 보내지 않습니다.

권한
항목/단가/펀딩 현재값 설정은 방송국 관리자만 가능합니다. 매니저는 부여된 입력·수정·승인 권한 범위에서 체크 입력·횟수 조정을 사용합니다.

적용
전체 수정 소스입니다. 기존 .env / data / uploads를 유지하고 적용·재배포 후 콘솔에서 Ctrl+F5를 누르세요. 기존 수정과 탭 속도 개선도 모두 포함합니다. 추가 SQL 실행은 필요하지 않습니다.

검증
서버 회귀 테스트 18개와 브라우저 테스트 4개를 실행했습니다. 프리셋 체크·금액 채우기·펀딩 선택·단가/현재값 저장·횟수 조정·분배 승인 체크·모바일 폭·매니저 제한을 확인했습니다.
예시: 23800을 두 방송인에게 11900씩 분배하면 흡연 프리셋은 각 1회, 펀딩 진행은 전체 2.38, 후원 매출은 23800 한 번입니다.
실제 서버 배포와 실제 은행/유튜브 계정 전송은 이 환경에서 수행하지 않았습니다.
