백수배 슈퍼스타 — GitHub 업로드 배포용

첨부해주신 server(1).js를 기준으로 노래대회 API 연결을 추가했습니다.

1. 압축을 풉니다.
2. 압축 안 server.js와 song-contest.js는 기존 GitHub 프로젝트 루트(server.js가 있던 위치)에 올려 교체합니다.
3. public 폴더 안 파일은 기존 public 폴더에 합쳐 올립니다. 기존 public 폴더 전체를 삭제하지 않습니다.
4. GitHub 변경 내용을 커밋하고 기존 서버를 재배포합니다.
5. Supabase에서 sql/20-song-contest.sql을 아직 실행하지 않았다면 한 번 실행합니다. 이미 실행했다면 생략합니다.
6. 관리자 페이지에서 Ctrl+F5로 새로고침합니다.

별도의 node install-song-contest.js 실행은 필요 없습니다. 연결 코드가 server.js에 이미 들어 있습니다.
기존 프로젝트의 다른 파일은 그대로 유지하세요. 이 압축은 전체 서버가 아니라 교체·추가 파일 묶음입니다.
후원은 수동 입력이며, 방송국 관리자 로그인 후 운영합니다.

변경 범위: 원본 server.js에 노래대회 연결 주석 및 require 한 줄만 삽입.
검증: JS 구문 검사 및 노래대회 자동 검사 11건 통과.
운영 서버 배포와 실제 Supabase 연결은 이 환경에서 수행하지 않았습니다.
