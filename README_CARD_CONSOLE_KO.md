# 카드형 운영 콘솔 · 오버레이3 기본 패치 (2026-10-14)

## 변경 사항
- 로그인 성공 후 운영 홈으로 이동합니다.
- 운영 홈: 후원 관리 / 방송 운영 / 오버레이3 / 내역·정산 / 연결·설정 카드.
- 후원 수동 입력, 승인 대기, 최근 입력을 같은 화면에서 유지합니다.
- PC와 모바일 화면에 맞춰 카드 수와 메뉴 배치를 조정했습니다.
- 방송국 로그인에 관리자·매니저 역할 설명, 비밀번호 보기, 진행·오류 안내를 추가했습니다.
- 콘솔과 기존 관리 화면의 기본 오버레이 링크가 overlay3.html을 사용합니다.
- 오버레이3 접근은 다른 송출 화면과 동일하게 방송국 토큰을 확인합니다.
- 오버레이3 방송 타이머 표시 선택 항목과 숨김/표시 스타일을 연결했습니다.
- 콘솔 내부에서 로그인 화면으로 이동되면 내부 로그인 화면 대신 재로그인 안내를 보여줍니다.

## 적용
1. 현재 서버 소스와 설정을 백업합니다.
2. 압축 안의 dona-overlay 소스를 적용합니다. 기존 환경변수, .env, 서버 data, 사용자 업로드는 유지하세요.
3. 의존성이 없는 환경이면 npm ci 후 기존 배포 방식으로 서버를 재시작합니다.
4. /station_login.html 접속 → 방송국 관리자 또는 매니저 로그인.
5. 오버레이 메뉴 → 알림·송출 주소 → 기본 오버레이3 주소 복사.
6. OBS·PRISM의 현황 브라우저 소스 주소를 새 주소로 바꿉니다. 기존 overlay.html 주소는 그대로 기존 화면입니다.

이번 패키지에는 .git, node_modules, 실제 data 파일, .env, 사용자 uploads를 넣지 않았습니다.
DB 변경은 이번 카드 디자인 패치에 필요하지 않습니다. 기존 운영 DB를 그대로 사용합니다.
이 압축은 수정 소스이며 실제 서버 배포는 아직 수행하지 않았습니다.

## 검증
- 기존 npm test 9개 통과.
- 브라우저: 홈 카드 메뉴, 100원 후원 저장, 웹소켓 이벤트 중 입력값 유지.
- 브라우저: 관리자/매니저 메뉴·권한, 매니저 로그인 역할·비밀번호 표시.
- 브라우저: 오버레이3 토큰 포함 링크, 방송 타이머 선택·숨김.
- 화면 폭 1440 / 1024 / 768 / 430 / 390px의 홈·후원 페이지 가로 넘침 확인.
- 후원 알림의 시작·대기·종료 기존 브라우저 테스트 통과.
- 실서비스 계정과 실제 후원·은행 연결은 이 환경에서 검증하지 않았습니다.
